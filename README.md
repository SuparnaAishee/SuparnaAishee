## 👩‍💻 About Me

I'm a **full-stack developer** with around a year and a half of professional experience building and shipping production web applications. I enjoy owning features end to end — from database schema and REST APIs through to responsive, polished interfaces.

- 🔭 I build with **React, Next.js, TypeScript, Node.js, Express, and PostgreSQL**
- 🤖 I work hands-on with **AI/LLM integration** (Claude, Gemini) and have trained & deployed **deep-learning models** into live web apps
- 📄 Co-author of **two IEEE international research papers** on applied AI
- 📦 Author of a published **npm authentication package** used by other developers
- 🌱 Always learning by building real things
